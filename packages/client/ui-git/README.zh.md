# @deepseek-ai/dsh-client-ui-git

[English](README.md) | 中文

编辑器标签页内的版本控制：选择仓库、审阅改动、暂存或丢弃、提交，并查看提交图谱。

## 本包注册什么

一个 `conversation.view.editor.panel` 条目（`id: 'git'`，`order: 10`）——位于编辑器标签页**内部**的面板，而非独立的标签页。

这一放置就是设计本身。审阅改动与编辑改动共享同一棵文件树、同一个缓冲区、同一个会话；两个并列标签页会把三者都复制一遍，并把一条工作流劈成两半。点击一个已改动文件会在编辑器自己的缓冲区中打开它，而重写了当前打开文件的丢弃操作会请求编辑器重新加载。

## 每个工作区的仓库

选择器列出**所有**已注册工作区下找到的仓库，而不只是会话自身的目录，并标记嵌套的那些。带子模块的 monorepo 与放着多个项目的机器都出现在同一个列表中。

## 每个检出，以及其中有什么

当仓库拥有多个检出时，面板会列出它们，逐个显示分支、状态与**改动数量**——因此无需逐个打开即可看到每个检出里有什么。改动操作寻址当前显示的检出：每个工作区拥有自己的索引，在一个里暂存绝不能触碰另一个。锁定与目录已丢失的检出被标出且不可进入，因为二者都改变了此处可做的事。

## 推送前的告警

当 `main` 或 `develop` 在脚下前进时，面板会说明前进了多少；若合并回去会冲突，告警转为红色。检查使用 `merge-tree`，它不移动任何 ref 也不写入任何文件。仅仅领先不会告警——那是进行中工作的常态。

## 图谱

`Changes | Graph` 切换器显示提交图谱：泳道以 SVG 绘制，合并画成汇聚的线束，分支尖端带标签。图谱只在其显示时读取，因为它是本面板最昂贵的调用。

## 查看改动内容

选中一个已改动的文件会就地展开它的 diff，使用共享的 `DiffBlock` 绘制。没有未暂存改动的文件与 HEAD 比较；其余情况比较工作区，也就是人正在看的那一侧。在编辑器缓冲区中打开文件是旁边独立的 **Open** 操作，因此审阅永远不会意外跳走。

## 丢弃会说明工作去了哪里

丢弃会销毁未提交的工作。宿主在恢复之前先保留被替换的内容并返回其对象 id，面板会报告该 id，而不是让改动悄然消失——这正是"可撤销的丢弃"与"不可撤销的丢弃"之间的差别。

## 两种提交方式

| 路径 | 作用 | 何时合适 |
|---|---|---|
| **Commit** | 经 `git.commit` RPC 直接写入 | 操作者自己的动作，与旁边编辑器的保存相同 |
| **Commit via agent** | 提示会话的 agent 运行 `git_commit` | 提交应当出现在会话日志中 |

直接按钮是对本仓库 *model-visible ⟺ logged* 规则的明确例外，之所以采纳，是因为从面板发起的提交与旁边编辑器中保存的文件地位相同。agent 路径为需要审计轨迹的人而存在；[Agent Note](../../../.agents/notes/implemented/architecture/2026-08-23-git-capability-seam-and-editor-panel.md) 记录了这一取舍。

## Model Experience

无：本包为人渲染仓库状态，不触及任何提示词、消息、schema、流或工具结果。面向模型的 Git 工具位于 [`dsh-tool-git`](../../git/tool-git/README.md)。

#### KV Cache 影响

无；本包从不组装或发送提供方请求。

## Known Limitations and Deferred Work

- **没有按 hunk 暂存** —— 暂存以文件为单位；`git.stage` 接受路径，hunk 协议尚无消费方。
- **diff 是整文件而非逐 hunk** —— `DiffBlock` 完整绘制两侧，因此超大文件会渲染其全部内容，而不仅是发生变化的区域。
- **一次只提供一个恢复项** —— 面板显示最近一次丢弃的 id，因此在关闭提示前连续丢弃两次，会使第一个 id 只能在宿主的对象数据库中找到。
- **没有 branch、merge 或远程控件** —— seam 不提供这些操作，本面板也不提供；`ahead`/`behind` 只报告而不提供协调手段。
- **列表不会自行刷新** —— 在面板之外发生的改动（agent 编辑了文件）会在重新选择仓库或某个操作结算时出现，因为宿主不发布仓库变更事件。
- **图谱不独立滚动** —— 它渲染宿主返回的提交并报告截断，但不会继续向更早处翻页。
